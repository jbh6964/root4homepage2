# root4 — living case studies

콜라주에서 프로젝트로 확대 진입한 뒤, 작업 설명과 결과물을 패럴랙스로 살펴보고 디테일 안의 다음 프로젝트로 이어지는 포트폴리오입니다. 현재 세 프로젝트는 실제 클라이언트 실적이 아닌 디자인 콘셉트 샘플입니다.

## 실행

Node.js 20.11 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm run dev
npm test
npm run build
```

개발 서버의 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. Vercel은 `vercel.json`의 설정으로 정적 파일을 `dist/`에 빌드합니다. 프로젝트의 Root Directory는 저장소 루트입니다.

## 경험 구조

`콜라주 → FORM / OTHER → 기획·아이덴티티·디지털 상세 → 디테일 확대 → mori → 브랜드·패키지·디지털 상세 → 디테일 확대 → OFFBEAT → 방향성·비주얼·인터랙션 상세`로 이어집니다.

- 상세 구간에서는 실제 스크롤 상세 페이지처럼 설명과 목업이 위로 이동합니다. 레이어별 이동 속도가 달라 패럴랙스가 생깁니다.
- 다음 프로젝트는 기존 작업물의 작은 인쇄 글자 안에 3×2px 크기로 중첩됩니다. 별도의 썸네일, 원형 구멍, 테두리를 표시하지 않습니다. 전체 장면이 함께 확대되며, 내부가 화면을 완전히 채운 뒤 같은 구도로 좌표계를 재설정합니다.
- 접힌 종이의 빛, 식물 실루엣, 섬세한 파형, 레코드와 목업이 반복해서 움직입니다. 카메라와 프로젝트 탐색은 자동 재생하지 않습니다.
- 하단 Motion 버튼으로 반복 모션을 멈출 수 있습니다. 메뉴 패널을 열거나 탭이 비활성화되면 반복 모션도 정지합니다.
- 휠·트랙패드, 방향키, Page Up/Down, Space/Shift+Space로 진행·복귀합니다. Home/End는 시작/끝, 하단 화살표는 이전/다음 구간으로 이동합니다.
- About / Lab / Contact는 모달 패널입니다. Escape로 닫으면 기존 위치에서 이어집니다.
- 폭 700px 이하 또는 동작 줄이기 환경에서는 설명과 목업을 포함한 일반 프로젝트 목록과 정적인 그래픽을 제공합니다.

## 파일

`geometry.js`: 구간별 카메라와 스크롤 경로. 확대 구간과 3개의 상세 구간을 구분해 로컬 좌표계에서 계산합니다.

`app.js`: 프로젝트 내용, 반복 그래픽, 상세 페이지 목업, 패널과 입력 처리.

`style.css`: 패럴랙스 레이아웃, 반복 모션, 모바일 대체 화면.

`vector-scene.js`: 네이티브 SVG 줌 장면. 텍스트·도형·그라디언트·중첩 프로젝트를 SVG로 직접 그리며 `viewBox`와 SVG 회전으로 카메라를 제어합니다.

`tests/geometry.test.js`: 확대·상세 전환 좌표 일치, 상세 종료·다음 진입의 연속성, 상세 구간 길이, 정방향·역방향 배율, 휠 단위 보정 검증.

## 디자인 방향

아이보리 용지, 짙은 잉크, 버건디 포인트를 중심으로 한 에디토리얼 디자인입니다. FORM / OTHER는 세리프 타이포그래피와 접힌 종이 조형, mori는 포레스트 컬러와 보태니컬 패키지, OFFBEAT는 흑백 타이포그래피와 선형 파형을 사용합니다. 상세 페이지와 디지털 목업도 같은 팔레트로 연결됩니다.

기존의 눈에 띄는 원형 미리보기를 제거했습니다. 다음 프로젝트는 작은 캡션과 라벨 인쇄에 섞여 있으며, 화면 좌표에 맞춰 이동하는 카메라가 확대 중에도 재질의 디테일을 유지합니다.

## 확대 렌더링

줌 공간에는 HTML 썸네일, CSS zoom/scale, foreignObject, 래스터 이미지나 필터를 사용하지 않습니다. 세 프로젝트의 원본 도형과 텍스트를 중첩 SVG로 보존하고, 매 프레임 `viewBox`를 변경하여 화면 해상도에서 그립니다. 좌표계를 재설정하는 시점에도 같은 경로·좌표·투영 크기를 유지합니다.

작은 디테일은 투영 크기에 따라 각 도형의 채움색과 선색이 재질의 기본색에서 원래 색으로 서서히 진해집니다. 장면 전체를 페이드하거나 고해상도 이미지로 교체하지 않습니다. SVG 반복 모션은 네이티브 애니메이션을 사용하며 메뉴·Motion 버튼·동작 줄이기 설정과 함께 정지합니다. 모바일 목록과 상세 목업은 일반 HTML로 제공합니다.
