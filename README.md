# Root4 — Good things connect.

전체 화면을 사용하는 디지털 디자인 스튜디오 포트폴리오입니다. 어두운 잉크색 공간의 빛나는 선을 따라 출발 → 이동 → 다섯 프로젝트 → Contact로 이어집니다. 인트로에서는 프로젝트 UI와 유체 그래픽을 노출하지 않습니다. 프로젝트와 수치, 제품, 콘텐츠, 업무 정보는 모두 **구성 예시**입니다. 실제 고객사 실적이나 검증 성과를 주장하지 않습니다.

## 실행

Node.js 20.11 이상에서 외부 의존성 없이 실행합니다.

- `npm run dev`: 개발 서버, 기본 포트 3000 (`PORT`로 변경).
- `npm test`: 경로, 카메라 연속성, 장면 경계, 도착 시간, 예시 데이터 검증.
- `npm run build`: Vercel에 배포할 정적 파일을 `dist/`에 출력.

Vercel Root Directory는 저장소 루트입니다. `vercel.json`에 빌드와 출력 경로가 지정되어 있습니다.

## 보존한 여정

기존 **7개 베지어 곡선의 제어점**과 휠 보정, 카메라의 경로 샘플링·확대·105ms 감쇠·역방향 이동을 보존했습니다. CONNECT → BALANCE → FRAME의 순서와 기존 도착 위치도 같습니다. OBJECTS와 RELAY는 FRAME 이후 남은 마지막 곡선의 94.5%, 98% 지점에 추가했습니다. 새 도착 구간은 기존 시간 모델을 사용합니다. 무한 줌이나 일반 세로 목록으로 데스크톱 여정을 교체하지 않았습니다.

`geometry.js`가 유한한 여정을 계산하고, `vector-scene.js`가 같은 카메라 좌표로 경로·작품·전경과 후경을 구성합니다. 화면 크기에 따라 작품의 구도와 크기를 맞춥니다. 이동과 도착의 경계에서 작품이 튀지 않도록 같은 장면 포즈를 공유합니다. 각 이동 구간은 다음 작품의 실제 UI·이미지·타이포를 크게 보여주며 작은 임시 카드나 와이어 필드는 사용하지 않습니다.

## 다섯 개의 아트디렉션

| 프로젝트 | 시각 언어 | 대표 인터랙션 |
| --- | --- | --- |
| CONNECT | 코발트·라임, 연결되는 웹·앱 모듈, 큰 산세리프 타이포 | 요금제 선택에 연결되는 UI 상태와 데이터 표시 |
| BALANCE | 라벤더·딥 바이올렛, 새틴 리본, 큰 자산 숫자와 도넛·흐름 차트 | 차트 드로잉, 금액 정리, 자산·월별 데이터 툴팁 |
| FRAME | 어두운 시네마 배경, 넓은 콘텐츠 월과 독자 제작한 세 가지 작품 이미지 | 포커스 프레임과 콘텐츠 프리뷰 전환 |
| OBJECTS | 라임 뉴트럴, 질감이 보이는 제품 사진과 에디토리얼 커머스 UI | 제품·옵션·가격·선택 영역 연결 |
| RELAY | 코랄·크림, 업무 맥락을 보여주는 협업 대시보드 | 같은 업무를 보드와 타임라인으로 전환 |

`/?project=connect`, `balance`, `frame`, `objects`, `relay`는 각 도착 장면을 직접 엽니다. 하단 01–05도 같은 도착 구간으로 이동합니다. 상세 패널에는 개요·과제·기획 판단·디자인 결과·담당 범위가 있습니다.

## 그래픽과 모션

`entrance-scene.js`는 네 가닥 흐름에 묶인 123개의 선을 서로 다른 깊이에 두고 원근 투영합니다. 스크롤 진행값으로 시점이 앞으로 이동하여 가까운 선은 바깥으로 벌어지고 먼 선은 깊이에 남습니다. 배경 이미지 확대나 자동 이동을 사용하지 않습니다. 한글 메시지는 짧게 사라지고, 기존 첫 이동 구간의 28%를 지난 뒤 CONNECT가 드러납니다. 기존 경로·스크롤 시간 모델은 변경하지 않았습니다. 선의 3D 깊이·굵기·빛을 직접 계산하며 화면 크기와 DPR 1.5까지 대응합니다. 모바일·동작 줄이기에는 같은 선으로 만든 정적 SVG 입구를 제공합니다.

`scene-effects.js`는 프로젝트 구간의 기존 재질 이미지를 스크롤 카메라에 맞춰 배치합니다. 인트로에서는 Canvas를 비우며, 포인터 추적·국소 굴절·틸트·패럴랙스·상시 RAF는 제거했습니다. UI 선택·차트 데이터 툴팁과 링크·버튼의 기본 커서·포커스·호버 표시는 유지합니다.
`scene-direction.js`는 다섯 장면의 색 전환·선택 상태·포커스·약 1.05초의 도착 연출을 관리합니다. 도착 시간은 카메라 제어와 분리되어 있습니다. 계속 스크롤하면 완료를 기다리지 않고 다음으로 이동하고, 경계 왕복이나 역방향 진입 시 완성 상태가 복원됩니다. 자동 카메라 이동과 강제 정지는 없습니다.

유체 리본·금융 리본·시네마 이미지·제품 사진은 이 사이트를 위해 제작한 독자적인 생성 이미지 자산입니다. 화면·차트·텍스트는 SVG로 그립니다. 새 이미지는 WebP로 압축하여 합계 약 1.4MB로 제공합니다. 로컬 Manrope와 Cormorant 폰트의 라이선스는 `assets/fonts/`에 있습니다.

## 메뉴·접근성·문의

About / Lab / Contact와 상세는 네이티브 `dialog`를 사용합니다. 패널이 열리면 카메라·도착 시간을 멈추고 내부 스크롤을 격리합니다. Esc·닫기·Tab 포커스 순환을 지원하며 닫으면 같은 여정 위치와 원래 버튼으로 돌아옵니다.

방향키, Page Up/Down, Space/Shift+Space, Home/End와 휠·트랙패드로 탐색합니다. 프로젝트 선택 컨트롤은 Tab·Enter/Space 및 좌우 방향키로 조작합니다. Ctrl+휠은 브라우저 확대를 유지합니다. Motion Off에서는 도착 연출을 완성 상태로 표시하고, 비활성 탭에서는 도착 시간을 멈춥니다. 입구는 스크롤 입력이 없으면 정지합니다.

780px 이하, 터치 포인터 또는 동작 줄이기 환경에는 같은 다섯 프로젝트를 완성된 정적 구도와 동일한 상세 내용으로 제공합니다.

마지막 화면과 헤더의 Contact는 같은 문의 패널을 엽니다. 실제 이메일·URL은 제공되지 않아 임의 주소를 넣지 않았습니다. `projects.js`의 `contact.email` 또는 `contact.url`에 확인된 채널을 입력하면 문의 링크가 활성화됩니다.
