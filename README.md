# root4 — worlds within work

콜라주에서 시작해 작업물·건축·풍경을 따라 탐색하고, 프로젝트마다 패럴랙스 상세를 읽는 스크롤 포트폴리오입니다. 세 프로젝트와 설명은 디자인 콘셉트 샘플입니다.

## 실행

Node.js 20.11 이상. 외부 패키지 설치 없이 `npm run dev`로 실행합니다. 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`로 좌표·경계·색 대비를 검사하고, `npm run build`로 정적 파일을 `dist/`에 만듭니다. Vercel의 Root Directory는 저장소 루트입니다.

## 탐색 흐름

콜라주 → FORM / OTHER 상세 → 종이 건축 도시 → 아치 너머의 산과 초원 → 나무 사이의 mori 상세 → 레코드 천문 작업실 → 떠 있는 풍경 → OFFBEAT 상세.

프로젝트를 작은 화면으로 반복해서 보여 주는 대신, 4개의 일러스트 세계를 경유합니다. 아치·나무의 틈·종이의 굴곡에 다음 장면이 실제로 중첩되어 있습니다. 같은 구리색 리본이 모든 장면을 연결하며, 입구의 위치·접선·폭을 맞춰 한 길처럼 이어집니다. 큰 프로젝트 제목은 상세 구간에서 표시합니다.

확대는 마우스 위치와 무관한 고정 경로입니다. 확대 공간 전체가 움직이고, 위로 스크롤하면 같은 경로를 되돌아갑니다. 카메라는 자동 재생하지 않습니다. 프로젝트 상세에서는 설명과 목업이 서로 다른 속도로 이동합니다.

## 렌더링

줌 공간은 네이티브 SVG입니다. HTML 썸네일, CSS 배율, foreignObject, 래스터 이미지나 필터로 확대하지 않습니다. `viewBox`를 갱신하며 화면 해상도에서 텍스트와 경로를 그립니다. 각 입구가 화면을 채운 뒤 같은 구도로 로컬 좌표계를 재설정합니다. 도형의 색 대비는 투영 크기에 따라 점진적으로 진해지며 장면 전체를 페이드하지 않습니다.

`geometry.js` — 장면 배치, 프로젝트/탐색 타임라인, 카메라와 입력 보정.

`worlds.js` — 종이 도시, 초원, 레코드 작업실, 떠 있는 풍경과 연결 리본.

`vector-scene.js` — 벡터 합성, 자연스러운 입구 마스크, 반복 모션, 점진적 색 대비.

`app.js` — 프로젝트 상세, 패럴랙스 목업, 메뉴와 입력 처리.

## 조작과 접근성

휠·트랙패드, 방향키, Page Up/Down, Space/Shift+Space로 진행·복귀합니다. Home/End는 처음/끝, 하단 화살표는 이전/다음 구간입니다. Ctrl+휠은 브라우저 확대를 유지합니다.

About / Lab / Contact 패널을 열면 카메라와 반복 모션이 정지합니다. Escape로 닫으면 같은 위치에서 이어집니다. 하단 Motion 버튼으로 반복 모션을 정지할 수 있습니다. 화면 너비 700px 이하와 동작 줄이기 환경에서는 설명과 목업을 포함한 정적인 프로젝트 목록을 제공합니다.
