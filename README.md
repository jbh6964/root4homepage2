# Root4 — Good things connect.

전체 화면을 사용하는 디지털 디자인 스튜디오 포트폴리오입니다. 어두운 잉크색 선형 공간에서 출발해 빛의 입구를 통과한 뒤, 펄 화이트 갤러리에서 다섯 프로젝트와 Contact를 만납니다. 같은 선과 주 경로가 전 구간에 이어지고, 프로젝트 UI는 그 공간 안에서 독립적으로 다가오고 스쳐 지나갑니다. 프로젝트와 수치, 제품, 콘텐츠, 업무 정보는 모두 **구성 예시**입니다. 실제 고객사 실적이나 검증 성과를 주장하지 않습니다.

## 실행

Node.js 20.11 이상에서 외부 의존성 없이 실행합니다.

- `npm run dev`: 개발 서버, 기본 포트 3000 (`PORT`로 변경).
- `npm test`: 경로, 카메라 연속성, 장면 경계, 도착 시간, 예시 데이터 검증.
- `npm run build`: Vercel에 배포할 정적 파일을 `dist/`에 출력.

Vercel Root Directory는 저장소 루트입니다. `vercel.json`에 빌드와 출력 경로가 지정되어 있습니다.

## 보존한 여정

기존 **7개 베지어 곡선의 제어점**과 휠 보정, 카메라의 경로 샘플링·확대·105ms 감쇠·역방향 이동을 보존했습니다. CONNECT → BALANCE → FRAME의 순서와 기존 도착 위치도 같습니다. OBJECTS와 RELAY는 FRAME 이후 남은 마지막 곡선의 94.5%, 98% 지점에 추가했습니다. 새 도착 구간은 기존 시간 모델을 사용합니다. 무한 줌이나 일반 세로 목록으로 데스크톱 여정을 교체하지 않았습니다.

`geometry.js`가 유한한 여정을 계산하고, `vector-scene.js`가 같은 카메라 좌표로 경로·작품·전경과 후경을 구성합니다. 인트로에서는 카메라가 진입점을 향해 확대되고, 통과 직후 한 번만 부드럽게 시야를 넓혀 첫 프로젝트 공간을 공개합니다. 화면 크기에 따라 작품의 구도와 크기를 맞추며 이동과 도착의 경계에서 작품이 튀지 않도록 같은 장면 포즈를 공유합니다. 각 이동 구간은 다음 작품의 실제 UI·이미지·타이포를 크게 보여주며 작은 임시 카드나 와이어 필드는 사용하지 않습니다.

## 다섯 개의 아트디렉션

| 프로젝트 | 시각 언어 | 대표 인터랙션 |
| --- | --- | --- |
| CONNECT | 코발트·라임, 연결되는 웹·앱 모듈, 큰 산세리프 타이포 | 요금제 선택에 연결되는 UI 상태와 데이터 표시 |
| BALANCE | 라벤더·바이올렛 데이터, 큰 자산 숫자와 도넛·자금 구성 차트 | 차트 드로잉, 금액 정리, 자산·흐름 항목 툴팁 |
| FRAME | 어두운 시네마 배경, 넓은 콘텐츠 월과 독자 제작한 세 가지 작품 이미지 | 포커스 프레임과 콘텐츠 프리뷰 전환 |
| OBJECTS | 라임 뉴트럴, 질감이 보이는 제품 사진과 에디토리얼 커머스 UI | 제품·옵션·가격·선택 영역 연결 |
| RELAY | 코랄·크림, 업무 맥락을 보여주는 협업 대시보드 | 같은 업무를 상태별·담당자별 관점으로 전환 |

`/?project=connect`, `balance`, `frame`, `objects`, `relay`는 각 도착 장면을 직접 엽니다. 하단 01–05도 같은 도착 구간으로 이동합니다. 상세 패널에는 개요·과제·기획 판단·디자인 결과·담당 범위가 있습니다.

## 그래픽과 모션

`entrance-scene.js`는 네 가닥 흐름에 묶인 123개의 선을 서로 다른 깊이에 두고 원근 투영합니다. 인트로·통과·이동·모든 도착·Contact까지 하나의 Canvas가 계속 유지됩니다. 입구의 밝은 영역이 넓어지면서 잉크색은 펄 화이트로, 선은 아이보리 빛에서 실버·딥 틸로 연속 전환됩니다. 밝은 구간에는 넓은 아이스 블루·라벤더 조명과 얕은 곡면 그림자를 같은 셰이더 안에 구성해 빈 흰 화면을 만들지 않습니다. 배경 깊이는 전체 스크롤 진행값에 연결되며, 프로젝트나 구간마다 다시 시작하지 않습니다. 도착 구간에서도 배경은 계속 전진하고, 스크롤을 멈추면 정지하며, 역방향에서는 같은 형상을 복원합니다. 전체 경로 너머까지 이어지는 선을 거리별 밀도로 샘플링하고 WebGL 단일 배치로 렌더링합니다. WebGL을 사용할 수 없으면 같은 기하와 명암을 Canvas2D로 그립니다. 렌더러와 기하 데이터는 데스크톱에서 처음 그릴 때 생성하여 정적인 모바일·동작 줄이기 환경에서는 만들지 않습니다. 포인터 추적·틸트·장식적인 호버 모션은 없습니다.

`journey-path.js`는 기존 카메라가 사용하는 7개 베지어 곡선을 주 경로로 그대로 그립니다. 카메라의 `routeDistance` 하나로 지나온 선의 끝과 현재 위치 광원을 계산하므로 정방향과 역방향에서 둘이 어긋나지 않습니다. 도착 구간에서는 같은 광원이 넓어져 프로젝트 가장자리 조명으로 연결되고, 하단 전체 진행 바는 같은 전역 진행값을 사용합니다.

`vector-scene.js`는 별도 투명 SVG 레이어에서 프로젝트를 그립니다. 각 이동에서 대표 구도의 12% 크기를 출발점으로 사용해 멀리서 다가오고, 도착하면 기존 카메라의 느린 이동을 따라 읽을 시간을 줍니다. 계속 진행하면 작품이 크게 옆으로 스쳐 나간 뒤 사라집니다. 배경 위에 프로젝트별 화면 전체 배경판을 두지 않습니다. 크롬·유체·금융 리본의 오브젝트, 이미지 파일, 전용 렌더러는 제거했습니다.

프로젝트 설명은 원근 변형을 받지 않는 고정 HTML입니다. 도착 구간에 짧게 나타나고 떠나기 전에 사라지며, 텍스트 영역에만 국소 그라데이션을 둡니다. `scene-direction.js`는 서비스 선택·차트 데이터·포커스·약 1.05초의 도착 연출을 관리합니다. 도착 시간은 배경·카메라와 분리되어 있고, 계속 스크롤하면 완료를 기다리지 않습니다. 경계 왕복이나 역방향 진입 시 완성 상태가 복원됩니다.

모바일·동작 줄이기에는 같은 선으로 만든 정적 SVG 공간과 동일한 프로젝트 내용을 제공합니다. 시네마·건축·제품 사진은 이 사이트를 위해 제작한 독자적인 생성 이미지 자산이며 WebP로 압축합니다. UI·차트·텍스트는 SVG로 그립니다. 로컬 Manrope와 Cormorant 폰트의 라이선스는 `assets/fonts/`에 있습니다.

## 메뉴·접근성·문의

About / Lab / Contact와 상세는 네이티브 `dialog`를 사용합니다. 패널이 열리면 카메라·도착 시간을 멈추고 내부 스크롤을 격리합니다. Esc·닫기·Tab 포커스 순환을 지원하며 닫으면 같은 여정 위치와 원래 버튼으로 돌아옵니다.

방향키, Page Up/Down, Space/Shift+Space, Home/End와 휠·트랙패드로 탐색합니다. 프로젝트 선택 컨트롤은 Tab·Enter/Space 및 좌우 방향키로 조작합니다. Ctrl+휠은 브라우저 확대를 유지합니다. Motion Off에서는 도착 연출을 완성 상태로 표시하고, 비활성 탭에서는 도착 시간을 멈춥니다. 전체 선형 공간은 스크롤 입력이 없으면 정지합니다.

780px 이하, 터치 포인터 또는 동작 줄이기 환경에는 같은 다섯 프로젝트를 완성된 정적 구도와 동일한 상세 내용으로 제공합니다.

마지막 화면과 헤더의 Contact는 같은 문의 패널을 엽니다. 실제 이메일·URL은 제공되지 않아 임의 주소를 넣지 않았습니다. `projects.js`의 `contact.email` 또는 `contact.url`에 확인된 채널을 입력하면 문의 링크가 활성화됩니다.
