# Root4 — 프로젝트를 따라가는 여정

차분한 출발 → 경로를 따라 이동·확대 → 프로젝트 도착과 설명 → 다음 이동 → 마지막 장면으로 이어지는 포트폴리오입니다. 기존의 7개 베지어 곡선과 유한한 카메라 공간을 유지합니다. 이번 버전은 통신 웹·앱 CONNECT, 금융 앱 BALANCE, TV 콘텐츠 UI FRAME의 세 가지 **구성 예시**를 보여줍니다. 실제 고객사 작업 실적·사용자 데이터·검증 성과를 주장하지 않습니다.

## 실행과 배포

Node.js 20.11 이상에서 외부 패키지 설치 없이 `npm run dev`로 실행합니다. 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`는 경로 연속성, 입력 보정, 프로젝트 순차 노출과 도착 설명을 검증합니다. `npm run build`는 정적 파일을 `dist/`에 만듭니다. Vercel의 Root Directory는 저장소 루트입니다.

## 출발과 도착

첫 화면에는 “하나의 경험에서, 다음 가능성으로.”와 출발점, 작은 UI 조각만 표시합니다. 별도 시작 버튼 없이 휠·트랙패드·키보드로 바로 탐색합니다. 미래의 프로젝트는 처음에 숨기고, 이동 진행값에 따라 다음 UI를 조금씩 드러냅니다. 3개 도착점은 기존 경로의 1번째·3번째·6번째 곡선 끝에 배치합니다.

카메라와 화면의 선은 같은 경로를 공유합니다. 이동의 기본 배율과 감쇠를 유지하고, 도착에서는 경로 이동량과 확대량을 완만하게 조절합니다. 각 도착의 4개 입력 진행 단위 전체에서 설명을 완전한 불투명도로 유지하므로 멈춘 위치에서 읽을 수 있습니다. 시간에 의한 자동 이동이나 강제 스크롤 정지는 없습니다. 역방향에서는 같은 진행값의 설명을 다시 표시합니다.

프로젝트명·분야·과제·담당 범위·상세 버튼은 크기가 고정된 HTML 설명 영역입니다. 대표 UI는 우측 공간으로 부드럽게 배치해 설명과 분리합니다. 하단 01–03을 선택하면 해당 도착의 읽기 구간으로 이동합니다.

## BALANCE 아트디렉션

BALANCE 한 장면을 먼저 완성했습니다. 라벤더·딥 바이올렛·밝은 뉴트럴, 큰 세리프 타이포와 독자 제작한 새틴 리본 자산을 자산 대시보드로 연결합니다. 자산 구성·6개월 흐름·최근 거래는 일관된 예시 데이터로 구성하며, 이동 중에도 같은 대시보드와 리본을 보여줍니다. CONNECT와 FRAME의 구성은 복제하거나 변경하지 않았습니다.

`/?project=balance`는 BALANCE 도착 구간을 직접 엽니다. 홈페이지의 기존 여정과 02 진행 표시에서도 같은 장면에 도달합니다. 카메라 경로와 프로젝트 순서, 스크롤 입력·감쇠는 변경하지 않았습니다.

`arrival-sequence.js`는 카메라와 별도로 1.05초의 도착 시간을 관리합니다. 프로젝트명·문구 마스크 리빌 → UI·리본 정렬 → 차트·숫자 정리 → 담당 범위·상세 버튼 순서로 진행합니다. 스크롤을 계속하면 기다리지 않고 지나가며, 세션 내 첫 진입 이후 경계를 오가거나 역방향으로 돌아와도 재생을 반복하지 않습니다. 메뉴와 상세 패널이 열린 동안에는 도착 시간도 정지합니다.

전경 UI와 후경 리본의 미세한 포인터 패럴랙스는 텍스트·버튼의 HTML 위치나 카메라를 움직이지 않습니다. 리본의 하이라이트는 이미지 알파 마스크 안에서만 이동합니다. 자산 차트·월별 차트에는 예시 데이터 툴팁을 제공하고, HTML 자산 범례는 키보드로도 선택할 수 있습니다.

`balance-art.js`는 대시보드와 예시 데이터, `balance-interaction.js`는 도착 연출·차트 반응·장면의 색 전환을 관리합니다. `assets/balance-ribbon.png`는 이 사이트를 위해 생성한 투명 배경의 원본 합성 자산입니다. 화면·차트·텍스트는 SVG로 선명하게 유지하고 리본만 이미지로 합성합니다. 로컬 Cormorant 폰트의 라이선스도 `assets/fonts/`에 포함합니다.

## 상세와 공통 패널

프로젝트 상세는 버튼을 선택했을 때만 네이티브 `dialog`로 엽니다. 개요, 과제, 기획 판단, 디자인 결과와 예시의 담당 범위를 제공합니다. About / Lab / Contact도 같은 패널 동작을 사용합니다.

열 때 현재 진행값을 저장하고 카메라·생성형 필드·포인터 반응을 정지합니다. 패널의 휠과 경계 스크롤은 배경에 전달되지 않습니다. 닫기 또는 Esc로 닫으면 정확한 진행값을 복원하고, 선택했던 버튼으로 포커스를 돌립니다. Tab / Shift+Tab은 패널 안에서 순환합니다. 패널 콘텐츠에도 키보드로 초점을 옮겨 스크롤할 수 있습니다.

## 문의 연결

실제 문의 이메일·URL이 제공되지 않아 Contact는 현재 안내 패널을 엽니다. `projects.js`의 `contact.email` 또는 `contact.url`에 확인된 주소를 설정하면 헤더·마지막 화면·모바일의 Contact에서 같은 문의 링크를 제공합니다. 주소를 임의로 만들거나 전송이 되지 않는 문의 폼을 표시하지 않습니다.

## 파일과 그래픽

- `projects.js`: 3개 구성 예시의 분야, 과제, 판단, 결과, 범위와 문의 설정.
- `project-art.js`: 통신 웹+앱, 금융 앱+데이터 컴포넌트, TV+콘텐츠 UI를 서로 다른 비율과 구도로 그리는 원본 SVG.
- `geometry.js`: 기존 경로, 3개 도착점, 유한한 타임라인, 순차 노출과 입력 보정.
- `vector-scene.js`: 전체 공간의 벡터 UI, 부분 경로와 포인터 깊이 레이어.
- `scene-effects.js`: 같은 카메라 좌표를 사용하는 Canvas 라이트 필드. 약 24fps, DPR 최대 1.25. 첫 화면과 작은 화면에서는 루프를 중지합니다.
- `app.js`: 출발·도착 설명, 진입점, 공통 패널, 스크롤·키보드 입력과 정확한 복귀.

프로젝트의 화면과 텍스트는 SVG viewBox에서 렌더링합니다. 기존 화장품·LP·조명·인쇄물 이미지는 화면에서 사용하지 않습니다. Manrope는 로컬 WOFF2로 제공하며 라이선스는 `assets/fonts/`에 있습니다.

## 접근성과 조작

휠·트랙패드, 방향키, Page Up/Down, Space/Shift+Space로 진행·복귀합니다. Home/End는 처음과 마지막으로 이동합니다. Ctrl+휠은 브라우저 확대를 유지합니다. 포인터 반응은 카메라 경로를 바꾸지 않습니다.

780px 이하, 터치 포인터 또는 동작 줄이기 환경에서는 같은 3개 프로젝트의 설명·상세·마지막 Contact를 정적 목록으로 제공합니다. 상단 번호는 해당 목록으로 이동합니다. 메뉴·상세·Motion Off·비활성 탭에서는 반복 모션을 정지합니다.
