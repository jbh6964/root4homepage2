# root4 — nested portfolio

밝은 콜라주에서 세 프로젝트 내부로 연속 확대하는 포트폴리오입니다. 현재 그래픽과 소개는 실제 작업물로 교체할 수 있는 샘플입니다.

## 실행과 검증

Node.js 20.11 이상. 외부 패키지 설치 없이 `npm run dev`로 실행합니다. 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`는 좌표 전환, 화면 크기별 카메라, 정방향·역방향 경로, 휠 입력 보정을 검사합니다.

## 탐색

휠·트랙패드, 방향키, Page Up/Down, Space/Shift+Space로 진행·복귀합니다. Home/End는 시작/끝으로 이동합니다. 하단 화살표는 이전·다음 프로젝트로 이동합니다. Ctrl+휠은 브라우저 기본 확대를 유지합니다.

About / Lab / Contact는 모달 패널을 엽니다. 패널이 열리면 현재 카메라 위치에서 멈추며 Escape로 닫을 수 있습니다. 폭 700px 이하 또는 동작 줄이기 설정에서는 일반 프로젝트 목록을 제공합니다.

## 구성

`geometry.js`는 화면 크기에 맞춰 중심, 로그 배율, 각도를 보간합니다. 프로젝트는 실제 DOM으로 내부에 중첩되어 있습니다. 경계에서 같은 구도를 유지하며 로컬 좌표계로 재설정해 배율 누적을 제한합니다. 다음 프로젝트를 페이드로 교체하거나 전체 화면으로 복귀하지 않습니다.

`app.js`에서 프로젝트 내용과 그래픽을, `style.css`에서 디자인을 변경할 수 있습니다. 저장소에는 기존 앱이 없어 새 구현을 추가했습니다. 첨부 이미지가 전달되지 않아 텍스트 디자인 요구사항을 기준으로 제작했습니다.

## Vercel 배포

`npm run build`는 필요한 정적 파일을 `dist/`로 복사합니다. `vercel.json`에 빌드 명령과 출력 디렉터리를 지정했습니다. Vercel 프로젝트의 Root Directory는 이 저장소 루트로 지정하세요. 앱 소스와 배포 설정이 GitHub의 배포 대상 브랜치에 반영된 뒤 재배포해야 실제 주소에서 확인할 수 있습니다. `npm start` 서버는 로컬 개발용이며 Vercel에서는 정적 파일을 제공합니다.

### 깊이 탐색 경로

현재 경로는 `콜라주 → FORM / OTHER → 물성 내부 → 미세한 패턴 → mori → 유기적 구조 → 주파수 패턴 → OFFBEAT`의 7개 확대 구간입니다. 다음 프로젝트는 두 겹의 내부 공간 뒤에 작은 크기로 실제 중첩되어 있어 처음부터 목적지가 드러나지 않습니다. 각 구간은 좌우·상하로 휘는 경로를 사용하고, 프로젝트 정보는 작업물을 인지할 수 있는 구간에만 나타납니다. 모든 카메라 계산은 현재 장면의 로컬 좌표계에서 수행합니다.
