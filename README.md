# root4 — a journey through work

전체 프로젝트 플로우를 먼저 보여 주고, 스크롤하면 같은 경로를 따라 이동·확대하는 포트폴리오입니다. 프로젝트 지점에서 상세 패럴랙스가 펼쳐지고, 계속 스크롤하면 다음 프로젝트로 지나갑니다. 현재 여섯 작업물과 설명은 디자인 콘셉트 샘플입니다. 각 프로젝트는 전용 벡터 그래픽과 색상 팔레트를 사용합니다.

## 실행

Node.js 20.11 이상. 외부 패키지 설치 없이 `npm run dev`로 실행합니다. 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`로 경로·프로젝트 위치·연결·입력을 검증하고, `npm run build`로 정적 파일을 `dist/`에 만듭니다. Vercel의 Root Directory는 저장소 루트입니다.

## 흐름

전체 플로우 → FORM / OTHER → mori → OFFBEAT → LUMA → STILL ROOM → INDEX / 06 → 여정의 끝. 각 프로젝트에서는 상세 패럴랙스를 읽은 뒤 다음 지점으로 이동합니다.

첫 화면에서 여섯 프로젝트와 시작·끝을 하나의 경로로 확인할 수 있습니다. 각 프로젝트는 같은 공간의 작업물 묶음으로 배치하며 내부에 다음 화면을 숨기지 않습니다. 작은 전체 지도는 확대 중인 위치를 보여 줍니다. Overview 버튼은 전체 플로우로 돌아갑니다. 첫 화면의 01–06 번호를 누르면 해당 프로젝트의 상세 구간으로 바로 이동합니다.

화면의 선과 카메라는 동일한 3차 베지어 경로를 사용합니다. 호 길이를 기준으로 이동해 굽은 곳에서 속도가 불필요하게 달라지지 않습니다. 프로젝트 지점에서 접선 방향을 맞추고, 프로젝트 상세 구간에서는 이동을 완만하게 유지하며 설명과 목업을 서로 다른 속도로 스크롤합니다. 카메라는 자동 재생하지 않습니다.

SVG viewBox로 전체 공간을 확대하므로 도형과 텍스트가 화면 해상도에서 그려집니다. 프로젝트 사이에 별도 장면을 교체하거나 다음 화면으로 페이드하지 않습니다.

## 파일

`projects.js` — 여섯 프로젝트의 제목, 설명, 범위와 메타데이터.

`project-art.js` — 프로젝트별 원본 SVG 그래픽과 팔레트. 전체 플로우·상세·모바일에서 공유합니다.

`geometry.js` — 전체 경로와 프로젝트 지점, 호 길이 샘플링, 카메라 타임라인과 입력 보정.

`vector-scene.js` — 전체 플로우, 프로젝트 작업물, 지나온 경로, 현재 위치와 작은 전체 지도.

`app.js` — 프로젝트 상세, 패럴랙스 목업, 메뉴와 입력 처리.

## 조작과 접근성

휠·트랙패드, 방향키, Page Up/Down, Space/Shift+Space로 진행·복귀합니다. Home/End는 처음/끝, 하단 화살표는 이전/다음 구간입니다. Ctrl+휠은 브라우저 확대를 유지합니다.

About / Lab / Contact 패널을 열면 카메라와 반복 모션이 정지합니다. Escape로 닫으면 같은 위치에서 이어집니다. 하단 Motion 버튼으로 반복 모션을 정지할 수 있습니다. 화면 너비 700px 이하와 동작 줄이기 환경에서는 설명과 목업을 포함한 정적인 프로젝트 목록을 제공합니다.
