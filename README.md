# root4 — a continuous material field

프로젝트 콜라주에서 출발해 종이 결·잉크·타이포그래피의 추상 공간을 탐색하는 포트폴리오입니다. 세 프로젝트와 설명은 디자인 콘셉트 샘플입니다.

## 실행

Node.js 20.11 이상. 외부 패키지 설치 없이 `npm run dev`로 실행합니다. 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`로 경로·속도·좌표·색 대비를 검증하고, `npm run build`로 정적 파일을 `dist/`에 만듭니다. Vercel의 Root Directory는 저장소 루트입니다.

## 공간과 카메라

줌 공간에 작은 프로젝트 화면, 라벨 속 화면, 창문, 포털, 풍경, 안내 리본을 배치하지 않습니다. 처음의 콜라주 이후에는 프레임 없이 겹쳐진 선과 인쇄 패턴이 공간을 구성하며, 확대에 따라 미세한 인쇄 결이 드러납니다. 프로젝트 상세와 목업은 이 공간 위의 별도 HTML 레이어입니다.

카메라는 전체 구간을 잇는 C1 연속 곡선을 따릅니다. 구간마다 목표물을 가운데 고정하거나 확대 속도를 0으로 만들지 않습니다. 읽기 구간에서도 느린 이동과 확대를 이어갑니다. 카메라는 자동 재생하지 않습니다.

네이티브 SVG `viewBox`로 확대하며 CSS 배율·HTML 썸네일·래스터 확대를 사용하지 않습니다. 좌표 기준이 바뀌어도 같은 벡터 DOM과 모든 상위 도형을 유지하므로 장면이 교체되지 않습니다. 미래 좌표는 수치 계산용이며 표시되는 타깃이 아닙니다. 인쇄의 밀도는 투영 크기에 따라 연속적으로 변합니다.

## 파일

`geometry.js` — 전체 비행 경로, 기울기 연속 보간, 좌표 변환과 입력 보정.

`vector-scene.js` — 원본 추상 패턴, 콜라주, 지속되는 벡터 DOM, 점진적 잉크 밀도.

`app.js` — 프로젝트 상세, 패럴랙스 목업, 메뉴와 입력 처리.

## 조작과 접근성

휠·트랙패드, 방향키, Page Up/Down, Space/Shift+Space로 진행·복귀합니다. Home/End는 처음/끝, 하단 화살표는 이전/다음 구간입니다. Ctrl+휠은 브라우저 확대를 유지합니다.

About / Lab / Contact 패널을 열면 카메라와 반복 모션이 정지합니다. Escape로 닫으면 같은 위치에서 이어집니다. 하단 Motion 버튼으로 반복 모션을 정지할 수 있습니다. 화면 너비 700px 이하와 동작 줄이기 환경에서는 설명과 목업을 포함한 정적인 프로젝트 목록을 제공합니다.
